# Arathy Dhandapani Portfolio

Static GitHub Pages portfolio for `arathydhandapani.github.io`.

## Update your content

Edit `portfolio-data.js` to update:

- email, phone, current location, LinkedIn URL, headline, about story, and current role
- projects and GitHub repository links
- degree and certifications
- blog cards and links
- skills grouped by category

## Add assets

- Replace `assets/profile.svg` with your professional photo. Update `profile.photo` in `portfolio-data.js` if the filename changes.
- Add your resume PDF at `assets/resume.pdf` so the Resume button downloads it.

## Publish on GitHub Pages

Copy these files to the root of your public GitHub Pages repository:

- `index.html`
- `styles.css`
- `script.js`
- `portfolio-data.js`
- `assets/`

Then commit and push to the repository used by GitHub Pages.
